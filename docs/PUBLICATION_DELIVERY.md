# Full-submission research delivery

`research.publication.publication_profile(config)` defaults to `full_submission`:
full-paper authoring, fifteen accepted comparable papers, three real datasets,
five strong baselines, five independent seeds/replicates and four component
ablations. These are editable starting design targets. A small compute budget
does not change the profile or declare a pilot to be the final deliverable.
An `operational` profile is an explicit selection for a task that does not request
a scientific submission.

The native workflow contains Literature Scout, Benchmark Curator, Experiment
Designer, Baseline Reproducer, Engineer, Experimenter, Analyst, Figure Designer,
Visual Selector, Layout Reviewer, Writer and Submission Reviewer. The common
research policy applies direct, evidence-calibrated judgments and the
anti-defensive writing contract to every role. Internal forecast worksheets do
not become compulsory manuscript prose. Unsolicited AI-writing statements are
excluded; material contrary results remain in the evidence and claims.

Press-Release style cannot delete core negative evidence or change a metric or
comparator to manufacture an advantage. Primary outcomes, units and comparable
budgets remain explicit. [Architecture visuals](SCIENTIFIC_VISUAL_NARRATIVE.md)
explain the specific mechanism and a grounded consequence; a simple supplied
method topology remains available when explicitly requested.

Agents use `literature_import` to retain real PDF pages and official publication
records, and `literature_read` to inspect original passages. Search metadata and
preprint presence cannot satisfy accepted/full-text coverage. `figure_create`
creates an editable specification from completed measured runs; `figure_render`
executes rendering and selection. `paper_generate` selects explicit completed
runs and actual rendered assets and submits full drafting, placement and
compilation. Creating a record or queueing work is not successful execution.

`submission_evidence.json` joins accepted-paper analyses, experiment design,
raw observations, independent analysis and review run IDs, and the compiled
manuscript. Its path can be configured in the publication profile. Each peer
analysis cites original passage IDs for relevance, experiment design, figures,
tables and adopted changes. Unreported peer counts are `null` with sourced
`scale_unknowns` explanations. A dimension contributes to a scale median only
when marked genuinely comparable in `scale_comparability`, with at least three
usable peers. Independent-unit targets additionally require the same
`unit_type` as the project `statistical_unit`. Training samples, benchmark
tasks, evaluation observations and retrieval inventories remain different
quantities. Main-body pages and words are counted from actual full text/PDF.

The primary effectiveness matrix covers all declared benchmarks, baselines,
candidate and independent seeds. Mechanism, scenario and alternative-explanation
studies declare relevant `datasets`, `methods`, `seeds` and `scope_rationale`.
Component ablations are assigned to relevant studies instead of multiplied
across unrelated benchmarks. Measured cells identify a completed run and raw
CSV/JSON artifact containing dataset, method, seed, study, independent unit ID
and finite numeric observations. The audit reads these rows and execution
receipts, checks units/data volume, and retains the remaining matrix explicitly.
Statistics bind effects and confidence limits to the actual independent
analysis measurements using JSON pointers.

The manuscript audit requires real compilation, a readable current PDF, clean
layout preflight, structured draft and actual LaTeX auxiliary placement report.
It checks the main Results comparison table, necessary mechanism illustration,
Results analysis figure, scientific duties, local references and page proximity
to their argumentative paragraphs. Accepted-paper length informs substantive
coverage; no fixed total figure count establishes quality.

The controller records an incomplete delivery as `needs_revision` and returns
to planning when an autonomous terminal proposal fails this audit. In assisted
mode, graph execution can finish while delivery remains `submission_incomplete`.
Resource limits preserve `budget_exhausted` with the current gaps. They never
produce a demo fallback or fabricated passing result. The final independent
review must have actual evidence and no unresolved delivery issues. All files,
parameters and decisions remain editable without content hashes or artifact
freezing. Delivery coverage and scientific judgments do not establish venue
acceptance.

Read or edit the default profile through `/api/publication-profile` and the
project `/api/projects/{id}/publication` endpoints. The project protocol
validation endpoint checks a full design's datasets, baseline rationale,
repetitions, ablations, four experimental duties, leakage/confirmation rules
and accepted-source references before execution; it reports structural scope
explicitly rather than claiming measured validation.
