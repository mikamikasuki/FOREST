# FOREST integration contract
Backend port 8000; Vite 5173 with /api and /ws proxy. Plain JSON objects (no data wrapper), error {detail:{code,message,retryable,suggestion}}. IDs UUID strings; timestamps ISO. sqlite fallback; PostgreSQL preferred. Root repo path forest/.

Project: {id,name,description,goal,current_direction,revision:int,archived:bool,mode:auto|assisted|manual,budget:{max_runs,seconds,allow_paid},created_at,updated_at}; list GET /api/projects -> array, POST create, PATCH /api/projects/:id. GET /api/projects/:id returns project.
Graph GET /api/projects/:id/graph -> {project_id,revision,nodes:[],edges:[],branches:[]}. Node {id,project_id,branch_id,type,title,instructions,revision,config:{},position:{x,y},execution_status,research_status,deliverable_status,archived,inputs:[],outputs:[],context_overrides:{},comments:[]}. Edge {id,source,target,relation} dependency relation is depends_on or consumes; source precedes target. Branch {id,name,root_node_id,status,workspace,is_main,config:{}}.
POST graph/preview and graph/commands body {request_id,expected_revision,operation,targets:[],params:{},run:false}. Operations per user spec. add_node params may contain node fields; edit_node targets[0] with params patches; add_dependency params {source,target,relation}; layout via edit_node position. Response apply {revision,graph,impact,run_ids:[]}. Impact {changed_nodes,affected_nodes,rerun_nodes,refresh_nodes,reasons,files,conflicts}.
GET /api/nodes/:id/context -> context packet. PATCH /api/nodes/:id with fields and expected_revision optional. POST /api/nodes/:id/run {request_id,scope:single|ancestors|descendants|affected}. GET /api/projects/:id/runs -> array. Run {id,node_id,project_id,branch_id,kind,status,config,node_revision,created_at,started_at,finished_at,exit_code,pid,error,metrics:{},output_path}. POST /api/runs/:id/{pause,resume,cancel,retry}; GET /api/runs/:id/output?offset=0 -> {text,offset,status}; GET /api/runs/:id -> run.
GET /api/projects/:id/files -> {files:[{path,size,modified,is_dir}]}; GET /api/projects/:id/file?path=... -> {path,content,revision}; PUT same {path,content,expected_revision}; DELETE same; GET /api/projects/:id/download?path=... streams; POST /api/projects/:id/upload multipart file.
GET /api/providers -> array without keys; POST /api/providers {name,kind:ollama|openai,base_url,model,api_key?,allow_paid:false,config:{}}; PATCH /api/providers/:id; POST /api/providers/:id/test real request. GET /api/hosts; POST /api/hosts; POST /api/hosts/:id/test. GET /api/system -> {cpu_percent,memory, disk,gpu,workers,latex,model_connected}. GET/PATCH /api/settings. GET/POST/PATCH /api/agents.
Generic research records GET /api/library?project_id= /api/experiments?project_id= /api/figures?project_id= /api/ideas?project_id= /api/theories?project_id= /api/analyses?project_id= -> array. Record {id,project_id,title,revision,status,data:{},created_at,updated_at}. POST each accepts {project_id,title,data}; PATCH /api/<resource>/:id {title?,data?,expected_revision?}; DELETE same.
POST /api/library/search {query,source:crossref|arxiv,limit:8} -> {results:[{title,authors,year,doi,arxiv_id,url,abstract,bibtex,source,...}]}; POST /api/library/import {project_id,identifier?,paper?}; GET /api/library/:id/passages.
POST /api/research/ideas {project_id,prompt,count?} -> queued run; POST /api/ideas/:id/adopt -> graph; POST /api/research/suggest-paths {project_id,node_id,prompt} -> queued run.
POST /api/theory/check {project_id,expression,variable?,kind:simplify|differentiate|solve|numeric} -> checked result and record.
POST /api/experiments/:id/launch -> run; POST /api/analysis/run {project_id,run_ids?,baseline?,metric?} -> queued run; POST /api/experiments/compare {run_ids} -> actual metrics.
POST /api/figures/:id/render -> queued run; POST /api/figures/:id/revise {instruction,expected_revision,region?} -> queued run. Figure data {kind:bar|line|method,run_ids:[],metric,style:{title,xlabel,ylabel,color,width,height,font_size},code,outputs:{}}.
GET /api/papers/:project_id -> {id,project_id,title,revision,status,data:{source,bibtex,pdf_path,log,bindings:[]}}; PATCH same {data:{source,...},expected_revision}; POST same /{compile,check,export,revise}. compile -> run; check -> {issues:[]}; export -> ZIP. POST /api/projects/:id/export -> zip. POST /api/projects/import multipart file.
GET /api/projects/:id/events SSE named events; UI refresh authority on events. Websocket /ws/projects/:id/terminal exchanges raw text; supports real PTY. Owner cookie auto established local only; remote/visitor protected. Public share /api/shares/:token only GET selected redacted objects.

CLI uses the same API and graph/run revision contracts. GET /api/projects/:id/usage reports project limits, estimated_cost_usd, reserved_usd, uncertain_requests, remaining_usd, run_count, elapsed_seconds, active_run_limits and provider summaries. Provider summaries use scope:all_projects; they are not project-only allowance. Unknown limits are null. POST paper export accepts expected_revision; PDF export requires compiled_revision == revision and returns STALE_PDF otherwise. Directory .forest/project.json stores a client binding only, never a second research database. See docs/CLI.md for commands and exit codes.
Research implementation python functions receive actual paths/config, no DB import. Graph kernel operates graph dict and BranchWorkspace filesystem independent of API.
